# Projet 1 : Gestionnaire de Dépenses Personnelles (CLI)

Une application en ligne de commande (CLI) écrite en Python permettant d'enregistrer, de classer et de suivre des dépenses financières quotidiennes avec une sauvegarde persistante au format CSV.

## 📌 Fonctionnalités
- **Ajout de dépenses** : Entrée interactive du montant, de la catégorie et d'une description.
- **Visualisation sous forme de tableau** : Affichage clair avec calcul automatique du total cumulé.
- **Filtrage ciblé** : Recherche de dépenses par catégorie spécifique.
- **Persistance des données** : Stockage automatique dans le fichier `expenses.csv`.

## 🛠️ Concepts Python appliqués
- Manipulation de fichiers et module standard `csv`
- Gestion des dates et heures via `datetime`
- Traitement des exceptions avec `try / except`
- Modularité du code à l'aide de fonctions bien définies
